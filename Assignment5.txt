What I learned:
    I leaned about the abstract keyword.
    It is used when declaring a class or method, to make it impossible to create an object of said class.
    An abstract class can however be use by another class that extends it, and an abstract function has no body until a class that extends it provides one.
    This is really useful if you have several classes that share some behavior, but the class that has that behavior isnt enough to use by itself.
    Doing this helps reuse code and keep everything neat and ordered, and prevents accidental usage of classes that do not do anything on thier own.
